# 서류함 대시보드 — 구글 드라이브 연동 설정 안내

한 번만 해 두면 됩니다. 총 소요 20~30분.

## 0. 먼저 알아둘 것
- 대시보드 HTML을 **컴퓨터에서 더블클릭(file://)로 열면 구글 로그인이 되지 않습니다.** 구글이 "주소가 있는 사이트"에서만 로그인을 허용하기 때문입니다.
- 그래서 HTML을 **Vercel에 올려서 https 주소로 여는 것**이 가장 편합니다. (아래 1단계)
- 드라이브 권한은 `drive.file` 범위만 씁니다. 이 앱이 만든 파일·폴더만 보고 쓸 수 있고, 드라이브의 다른 파일은 건드리지 못합니다.

## 1. HTML을 Vercel에 올리기 (5분)
1. 컴퓨터에 폴더 하나를 만들고(예: `seoryuham`) 그 안에 `자료정리대시보드.html`을 **`index.html`** 로 이름을 바꿔 넣습니다.
2. https://vercel.com/new 접속 → 로그인 → 화면 아래쪽 드래그 영역에 이 폴더를 통째로 끌어다 놓습니다. (또는 Vercel CLI: 폴더에서 `vercel --prod`)
3. 배포가 끝나면 주소가 나옵니다. 예: `https://seoryuham.vercel.app`
   → 이 주소를 메모해 두세요. 2단계에서 씁니다.

## 2. Google Cloud에서 클라이언트 ID 만들기 (15분)
1. https://console.cloud.google.com 접속 (penielclinic 구글 계정으로 로그인)
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `서류함` → 만들기 → 만든 프로젝트 선택
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용(Enable)**
4. **API 및 서비스 → OAuth 동의 화면**
   - 사용자 유형: **외부(External)** → 만들기
   - 앱 이름 `서류함`, 사용자 지원 이메일·개발자 연락처에 본인 이메일
   - 범위(Scopes)는 그냥 저장하고 계속
   - **테스트 사용자(Test users)** 에 본인 구글 계정 이메일 추가 (직원 계정도 쓰려면 함께 추가)
   - 저장. 게시 상태는 "테스트" 그대로 두면 됩니다. (검증 신청 불필요)
5. **API 및 서비스 → 사용자 인증 정보(Credentials)** → **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 이름: `서류함 대시보드`
   - **승인된 자바스크립트 원본(Authorized JavaScript origins)** 에 추가:
     - `https://seoryuham.vercel.app`  ← 1단계에서 받은 주소 (끝에 `/` 없이)
     - `http://localhost:3000`  ← PC에서 시험용으로 열 때 (선택)
   - 리디렉션 URI는 비워 둡니다
   - 만들기 → **클라이언트 ID** 복사 (`…….apps.googleusercontent.com` 형태)

## 3. 대시보드에서 연결 (1분)
1. Vercel 주소로 대시보드를 엽니다.
2. 오른쪽 위 **"구글 드라이브 연결"** 클릭 → 클라이언트 ID 붙여넣기 → **저장하고 로그인**
3. 구글 로그인 창에서 계정 선택. "Google에서 확인하지 않은 앱" 경고가 뜨면 **고급 → 서류함(안전하지 않음)으로 이동** → 허용. (테스트 모드 앱에 항상 뜨는 경고입니다. 본인이 만든 앱이므로 괜찮습니다)
4. 연결되면 드라이브에 `서류함` 폴더가 자동으로 생기고, 단추가 "드라이브 연결됨"으로 바뀝니다.

## 4. 이후 사용법
- 파일을 넣으면 → 분류 후 `서류함/종류/연-월/날짜_거래처_파일명` 으로 자동 업로드 (목록의 ☁ 표시)
- 항목 정보를 고치면 → 드라이브의 파일명·폴더도 함께 옮겨집니다
- 삭제 → 드라이브 휴지통으로 이동
- 다른 컴퓨터나 휴대폰에서: 같은 주소 열기 → 드라이브 연결 → **"드라이브에서 불러오기"** 하면 목록 전체가 그대로 복원됩니다. 원본은 항목을 클릭할 때 드라이브에서 가져옵니다.
- 목록 정보(금액·거래처·읽어낸 본문 등)는 `서류함/index.json` 에 함께 저장됩니다.
- 로그인은 1시간마다 갱신되며, 한 번 연결한 브라우저는 다음에 열 때 자동으로 재연결을 시도합니다.

## 자주 생기는 문제
| 증상 | 원인 / 해결 |
|---|---|
| 로그인 창이 뜨자마자 `오류 400: redirect_uri_mismatch` 또는 `origin_mismatch` | 2-5단계의 승인된 자바스크립트 원본에 지금 열고 있는 주소가 정확히 없음. 주소를 그대로 추가 (http/https, 포트까지 동일해야 함). 저장 후 5분 정도 지나야 반영 |
| `액세스 차단됨: 이 앱은 확인되지 않았습니다` 에서 진행 불가 | 2-4단계 테스트 사용자에 로그인하려는 계정이 없음 |
| 연결됐는데 업로드 실패 | Drive API 사용 설정(2-3단계) 안 됨 |
| 6개월 지나 갑자기 로그인 요구 | 테스트 모드 앱은 7일마다 재동의가 필요할 수 있음. 다시 로그인하면 됨. 없애려면 OAuth 동의 화면에서 "앱 게시" (drive.file 범위는 검증 없이 게시 가능) |
